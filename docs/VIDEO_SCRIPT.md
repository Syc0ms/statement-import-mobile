# Сценарий видео (≈ 5–7 минут)

Уже готово: `docs/evidence/ios-sim/walkthrough.mp4` — вся матрица на iOS-симуляторе с подписями и
счётчиками `/__test/state` до/после (1 мин), полные записи — `docs/evidence/ios-sim/clips/`.
Этого ролика достаточно для части iOS. Запись с телефона — по желанию (показывает тот же
сценарий на реальном устройстве по LAN). Android в видео — честный кадр «не проверено».

**Запись на iPhone:** Пункт управления → «Запись экрана» (если кнопки нет: Настройки → Пункт
управления → добавить «Запись экрана»). Рядом на Mac — терминал со счётчиками:

```bash
while true; do clear; curl -s http://127.0.0.1:8787/__test/state | python3 -m json.tool; sleep 1; done
```

Перед каждым сценарием: «Тест-панель → Сбросить mock», затем нужный сценарий. На телефоне в
тест-панели адрес `http://<IP Mac>:8787` (mock запущен через `npm run mock:lan`).

## 0. Вступление (15 с)
- Показать репозиторий: `kit/` (не изменён, `git log -- kit` — один коммит), `app/`, `npm test` зелёный.
- Запущен mock: `npm run mock` (для телефона — `npm run mock:lan`).

## 1. iOS — happy (60 с)
1. Тест-панель: «Сбросить mock», сценарий `happy`. Счётчики все 0.
2. «Выбрать файл» → системный picker → `statement.csv`.
3. Экран подтверждения: имя, размер «112 Б», «CSV, определён по содержимому». «Отправить».
4. Показать таймлайн: «Отправка → В очереди (ревизия 1) → Обрабатывается → Готово (ревизия 3)».
   Подчеркнуть: после 202 экран говорит «В очереди», не «готово».
5. Результат: StreamBeam 19.99 AUD, BrightGrid 132.00 AUD, итого **151.99 AUD** в месяц.
   «Подробнее» → карточка (без кнопки отмены подписки) → «Закрыть».
6. Тест-панель: `createRequests 1, newJobs 1, acceptedBytes 112`, SHA-256 совпадает с локальным.
7. Повторить с `statement.pdf` (acceptedBytes 33882) — можно ускоренно.

## 2. iOS — lost_ack + relaunch (60 с)
1. Сбросить mock, сценарий `lost_ack`.
2. Выбрать `statement.csv` → «Отправить». Экран: «Исход отправки неизвестен», счётчик
   «Следующая проверка по ключу через N с».
3. Пока идёт отсчёт (первая проверка по ключу через 3 с) — закрыть приложение свайпом из
   переключателя приложений.
4. Открыть снова: запись восстановлена, GET по ключу находит задание, опрос → «Готово».
   Файл повторно не отправлялся.
5. Тест-панель: `createRequests 1, newJobs 1, duplicateHits 0`.
6. (Вариант) без перезапуска нажать «Отправить ещё раз с тем же ключом»: `createRequests 2,
   newJobs 1, duplicateHits 1` — второго задания нет.

## 3. iOS — stale_status (40 с)
1. Сбросить mock, сценарий `stale_status`.
2. Импорт `statement.csv` → первый GET сразу «Готово, ревизия 3».
3. Нажать «Обновить статус»: сервер вернул `processing/2`. Экран остаётся «Отчёт готов»,
   на шаге «Готово» подпись «устаревший processing/2 проигнорирован».
4. Упомянуть тест: `stale_status: processing/2 after ready/3 is ignored and the UI stays ready`.

## 4. iOS — delete_failure (60 с)
1. Сбросить mock, `happy`, импорт до «Готово».
2. Сценарий `delete_failure`. «Удалить с сервера» → подтвердить.
3. Экран: «Не удалено … сервер временно недоступен (503). Данные остаются на сервере».
   Результат всё ещё виден. `deleteRequests 1`, на mock задание `ready`.
4. Сценарий `happy`. «Повторить удаление» (в «Технических деталях» тот же ключ удаления, попыток 2).
5. «Удаляется» (202) → через ~1 с «Удалено с сервера», шаг «подтверждено GET · ревизия 5».
   `deleteRequests 2`, задание на mock `deleted/5`.

## 5. iOS — spoofed + oversize (40 с)
1. Запомнить `createRequests` в тест-панели.
2. Выбрать `spoofed.pdf` → «Это не PDF… содержимое не начинается с %PDF-. На сервер ничего не отправлено».
3. `npm run fixtures:oversize`, выбрать `oversize.csv` → «Файл больше 10 МиБ … содержимое не читалось».
4. `createRequests` не изменился.

## 6. Крупный шрифт и маленький экран (30 с)
- iPhone SE, Настройки → Универсальный доступ → Крупный текст (максимум). Пройти до результата:
  кнопки доступны прокруткой, ничего не обрезано. Тёмная тема.

## 7. Физический iPhone (30 с)
- `npm run mock:lan`, в тест-панели адрес `http://<IP Mac>:8787`, импорт до «Готово».

## 8. Android (30 с)
- Если Android не проверен: показать README, раздел «Android — НЕ ПРОВЕРЕНО», и сказать это вслух.
  Не заменять показом веб-сборки.
- Если проверен: те же шаги 1–2 на эмуляторе после `adb reverse tcp:8787 tcp:8787`.
